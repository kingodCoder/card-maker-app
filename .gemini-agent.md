# Gemini Agent Instructions for card-maker-app

This document provides instructions for the Gemini AI agent to effectively assist with development on this project.

## Project Overview

This is a web application for creating custom cards. It's built with React, Vite, TypeScript, and uses Tailwind CSS with Shadcn UI for styling.

## Commands

Always use `bun` to run commands.

- **Run development server:** `bun run dev`
- **Build for production:** `bun run build`
- **Run linter:** `bun run lint`
- **Preview production build:** `bun run preview`

## Tech Stack & Conventions

- **Framework:** React with Vite
- **Language:** TypeScript
- **UI:** Shadcn UI components are preferred. They are located in `src/components/ui`.
- **Styling:** Use Tailwind CSS utility classes. Avoid writing custom CSS files when possible.
- **State Management:** (Add any state management libraries you use, e.g., Zustand, Redux)
- **Routing:** React Router is used for navigation. See `src/pages` for existing routes.

## Goals & Constraints

- Maintain a clean and readable codebase.
- Ensure all new components are typed correctly with TypeScript.
- Do not add new dependencies without discussing it first.
